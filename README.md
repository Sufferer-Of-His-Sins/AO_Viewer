## Установка и запуск
**Для windows** 
скачать установщик и запустить

**Для Linux** 
```bash
# 1. Клонировать репозиторий
git clone https://github.com/Sufferer-Of-His-Sins/AO_Viewer.git
cd AO_Viewer

# 2. Создать виртуальное окружение (рекомендуется)
python -m venv venv

# Linux / macOS
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить
python main.py
```
